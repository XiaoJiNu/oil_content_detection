# 油茶籽含油率复现计划

## 1. 目标与预期成果

- 复现《基于高光谱成像的油茶籽含油率检测方法》中的实验流程，重建400–1 000 nm与900–1 700 nm双波段采集、变量筛选与PLSR建模。
- 输出高光谱数据处理管线、模型性能对照（R²、RMSEP、RMSECV）及含油率伪彩色可视化结果。
- 形成可复用的代码框架、数据管理规范与实验记录，支撑后续算法改进。

## 2. 数据资源与采集计划

- 已有资料：论文全文、需求文档；暂缺原始光谱数据与含油率实测值。
- 原始数据采集：规划两套系统（Spectral Set Ⅰ：400–1 000 nm；Set Ⅱ：900–1 700 nm）。按照论文参数设置：
  - Set Ⅰ：距样品300 mm，曝光1.2 ms，位移台0.6014 mm/s，分辨率800×664，扫描长度200 mm。
  - Set Ⅱ：距样品300 mm，曝光7.5 ms，位移台2.2568 mm/s，分辨率640×542，扫描长度200 mm。
- 样本准备：采集至少109颗油茶果，记录形态参数，次日剥壳取籽；逐粒采三颗取平均光谱。
- 含油率标定：使用NAI ZFCDY 6Z索氏抽提仪，按GB 5009.6—2016执行；每粒质量约2 g，抽提6 h，干燥称量后计算含油率。

## 3. 实验流程

1. **系统标定**：采集白板与暗场图像，按公式 `Re = (R0 - D)/(W - D)`完成黑白校正；剔除噪声波段（SetⅠ保留416.6–994.9 nm，SetⅡ保留1038.3–1564.9 nm）。
2. **ROI提取与数据整理**：对每颗籽获取ROI平均光谱；将光谱与含油率、采样元信息写入统一数据表（CSV/Parquet）。
3. **异常样本检测**：Monte Carlo交叉验证（5000次、训练/预测=2∶1）筛除异常样本，目标保留约102份。
4. **预处理对比**：实现原始、MSC、SNV、SG、Normalize、Detrend六条管线，基于PLSR评估潜变量数（最小RMSECV）。
5. **特征波长筛选**：复现SPA、CARS、PSO、ACO、SA、iRF、GA；采用论文参数（如GA：代数150、种群64、变异率1%；PSO：种群20、迭代1000，F=R²；ACO：蚁群30、迭代100、窗口1，F=(1+QRMSECV)/R²等），输出各自特征波段。
6. **模型训练与评估**：对全波段与筛选波段分别训练PLSR；记录R²c、R²p、RMSEC、RMSEP、RMSECV；重点验证SetⅡ + GA组合。
7. **可视化复现**：将最佳模型应用至高光谱立方体，生成含油率伪彩色图，分析边缘误差并与论文图4对照。
8. **结果汇总**：撰写实验记录（含数据分布、模型指标、误差分析），提供再现性说明。

## 4. 工具与环境

- 硬件：双波段高光谱成像系统、电控位移台、标准白板、索氏抽提装置、恒温干燥箱。

## 6. 风险与应对

- **数据缺失**：若无法立即获取原始光谱，先使用公开近红外数据进行算法验证，再迁移至实测数据。
- **算法复现难度**：优先使用论文参数，必要时查阅原作者参考文献；全部实现统一接口便于调试。
- **设备差异**：记录实际设备参数，必要时重新优化曝光与扫描速度；对比论文指标时注明差异。
- **模型泛化**：引入交叉验证与留一法评估稳定性；必要时增加正则化或多模型融合。

# 针对花椒含油量测量的改进思路

我现在要将《基于高光谱成像的油茶籽含油率检测方法》这个方法用于花椒的含油量检测，但是花椒的样本采集与论文中不太一样，所以需要专门进行改进。

## 数据情况

如docs/reference_docs/功能需求文档/20251118需求整理/0164_11.jpg这个图片所示，花椒含油量的一个样本是多颗花椒一起用光谱扫描，得到了光谱扫描数据，且数据已经经过黑白校正。

每个样本对应一个编号，以一个样本编号0164_11为例进行说明：

**扫描的光谱数据**：数据整体目录结构如docs/reference_docs/功能需求文档/20251118需求整理/一个样本数据的目录结构_整体.png所示，路径/home/yr/yr/data/科研数据/云南藤椒1-1/0164_11，其中0164_11是最外层目录名字。实际的光谱数据是docs/reference_docs/功能需求文档/20251118需求整理/一个样本数据的目录结构_实际数据.png中的REFLECTANCE_0164_11.dat和REFLECTANCE_0164_11.hdr。这是经过黑白校正后的数据。

对应的花椒图片为docs/reference_docs/功能需求文档/20251118需求整理/0164_11.jpg

**含油量数据**：在docs/2025年8月花椒挥发油测定结果.xls中，如图docs/reference_docs/功能需求文档/20251118需求整理/含油量数据.png所示，它对应高光谱图件编号0164-11那一行，蒸馏量（初）ml为0.5。

## 改进思路1

现在的实验数据是"一幅包含多粒花椒的图像对应一个含油量真值”**（即群体平均值对应群体光谱），那么论文中的核心算法流程（PLSR建模、特征波长筛选）是完全可用的，但在**数据预处理**和**ROI（感兴趣区域）提取**这两个环节需要针对花椒数据特性做重要的**逻辑修正**。

以下是改进方案：

### 1. 核心逻辑的转变：从“单体”到“群体”

论文的研究对象是**单颗**油茶籽，其流程是：提取单颗籽的平均光谱 **$\rightarrow$** 对应单颗籽的理化值 。

您的情况是群体花椒，您的流程必须调整为：

提取图中所有花椒像素的平均光谱 $\rightarrow$ 对应这一盘花椒的理化总值。

如果您试图分割出每一颗单独的花椒，因为您没有每一颗单独的含油率数据，强行将总含油率赋给每一颗花椒作为标签（Label）去训练，会引入巨大的标签噪声，导致模型失败。

---

#### 第一步：ROI 提取策略（关键修正）

论文中通过图像分割提取了单颗种子的ROI。对于您的多粒花椒图像：

* **原来的做法（论文）** ：提取整个种子的区域。
* **您的改进做法** ：

1. **HSV 阈值调参（推荐第一步）**：
   - 使用交互式调参工具 `src/oil_content_detection/preprocessing/hsv_tuner.py` 中的 `hsv_debugger` 函数
   - 在缩放后的图像（400宽）上实时调整HSV阈值，快速找到最佳分割效果
   - 退出时记录打印的HSV参数（如 `lower=[30,70,30]`, `upper=[65,255,255]`）

2. **批量生成掩膜（Mask）** ：
   - 使用 `scripts/generate_roi_masks.py` 在**原始尺寸**上对所有样本生成ROI掩膜
   - 默认参数 `--hsv-max-width 0` 表示不缩放，在原图尺寸上进行HSV分割
   - 该脚本仅执行纯HSV阈值分割，**不包含**边界裁剪、模糊、形态学操作、连通域筛选
   - 输出两个文件：
     - `<样本ID>_mask.png`：二值掩膜（0/255），与原图同尺寸
     - `<样本ID>_overlay.png`：叠加可视化，红色区域为ROI，便于人工检查

   示例命令：
   ```bash
   # 在原始尺寸上生成掩膜（推荐）
   python scripts/generate_roi_masks.py \
     --split data/labels/train.txt \
     --output-dir data/processed/ROI \
     --hsv-lower 30 70 30 \
     --hsv-upper 65 255 255

   # 可选：在缩放后生成掩膜（与调参器效果一致，用于快速预览）
   python scripts/generate_roi_masks.py \
     --split data/labels/train.txt \
     --output-dir data/processed/ROI_small \
     --hsv-lower 30 70 30 \
     --hsv-upper 65 255 255 \
     --hsv-max-width 400
   ```

3. **人工复核与修正**：
   - 检查生成的 `*_overlay.png` 文件，确认ROI是否正确覆盖花椒区域
   - 如有偏差，重新调参或手动修正掩膜文件

4. **像素清洗与空间平均（自动执行）**：

   使用 `scripts/build_huajiao_from_split.py` 完成以下处理：

   **4.1 像素清洗**（`clean_mask_extremes` 函数）：
   - **问题**：花椒表面皱缩严重，产生**高光点**（过曝）和**阴影深坑**（欠曝），这些像素是噪声
   - **方法**：计算掩膜内每个像素的全波段平均反射率，使用分位数阈值剔除极值
   - **默认参数**：
     - `clip_low = 0.01`：剔除最暗的1%像素
     - `clip_high = 0.99`：剔除最亮的1%像素
   - **输出**：清洗后的掩膜（`cleaned_mask`），记录剔除比例

   **4.2 空间平均**（`_aggregate_spectra` 函数）：
   - **方法**：对清洗后掩膜内的所有像素进行光谱聚合
   - **支持的统计量**：
     - `mean`：算术平均
     - `median`：中位数
     - `trimmed_mean`：修剪均值（去除两端极值后的均值，默认去除各10%）
     - `std`：标准差
   - **默认参数**：
     - `primary_stat = "trimmed_mean"`：主要统计量
     - `trim_fraction = 0.10`：修剪均值的裁剪比例
     - `include_stats = ["trimmed_mean"]`：输出的统计量（可包含多个）

   **完整命令示例**：
   ```bash
   # 使用预生成的mask（推荐）
   python scripts/build_huajiao_from_split.py \
     --split data/labels/train.txt \
     --output-dir data/processed/huajiao/train \
     --roi-dir data/processed/ROI \
     --roi-mask-dir data/processed/ROI \
     --trim-fraction 0.10 \
     --clip-low 0.01 \
     --clip-high 0.99 \
     --primary-stat trimmed_mean \
     --include-stats trimmed_mean

   # 或者实时HSV分割（不使用预生成mask）
   python scripts/build_huajiao_from_split.py \
     --split data/labels/train.txt \
     --output-dir data/processed/huajiao/train \
     --roi-dir data/processed/ROI \
     --hsv-lower 30 70 30 --hsv-upper 65 255 255 \
     --hsv-max-width 0 \
     --trim-fraction 0.10 \
     --clip-low 0.01 \
     --clip-high 0.99
   ```

   **参数调优建议**：
   - 如果花椒颜色差异大，增大 `trim_fraction`（如0.15-0.20），更激进地去除异常像素
   - 如果担心丢失有效数据，减小 `clip_low/clip_high` 的范围（如0.005/0.995）
   - 若需要多个统计量用于后续分析，设置 `--include-stats mean median trimmed_mean std`

   **输出文件**：
   - `huajiao_spectra.parquet`：特征表，每行一个样本，列为 `wl_<波长>`（主统计量）或 `wl_<波长>_<统计量>`
   - `huajiao_metadata.parquet`：元数据，包含 `pixel_count`（原始像素数）、`valid_pixel_count`（清洗后像素数）、`coverage_ratio`（覆盖率）等质控信息

* **结果** ：每张图最终生成**一条**平均光谱曲线，代表这盘花椒的整体特征，与理化值对应。

* **关键工具与函数**：
  - `hsv_tuner.py::hsv_debugger`：交互式调参
  - `hsv_tuner.py::apply_hsv_mask_simple`：纯HSV分割（无额外处理）
  - `scripts/generate_roi_masks.py`：批量生成掩膜
  - `pipelines/huajiao_dataset.py::clean_mask_extremes`：像素清洗
  - `pipelines/huajiao_dataset.py::_aggregate_spectra`：空间平均
  - `scripts/build_huajiao_from_split.py`：完整流程编排

#### 第二步：光谱预处理（针对性加强）

**论文中提到对于油茶籽，未经预处理的原始数据（Raw Data）在某些波段下效果最好 **^3^。但这对花椒可能不适用。

* **差异点** ：油茶籽相对圆润，花椒表面极其粗糙，光散射效应（Scattering Effect）极其严重。
* **改进建议** ：
* 不要直接信赖原始数据。
* **强制尝试 SNV（标准正态变量变换）和 MSC（多元散射校正）** **。论文中对比了 SNV 和 MSC ，这两种方法专门用于消除颗粒表面不平整导致的物理光程差异，对花椒这种物料是必须的。
* **导数处理** **：尝试一阶导数（SG平滑后求导）**，有助于提取油脂在特定波段的吸收峰，减弱背景基线干扰。

#### 第三步：特征波长选择（复用论文方法）

**论文比较了 SPA、CARS、PSO、ACO、SA、iRF、GA 等七种方法 。结论是 **GA（遗传算法）** 和 **CARS** 表现较好 。

* **直接应用** ：这一步不需要改。您使用计算出的“群体平均光谱”作为输入 **$X$**，含油量作为 **$Y$**，直接运行论文中提到的 CARS 或 GA 算法。
* **注意** **：花椒油（挥发油）和籽油的特征波段可能不同。论文中油茶籽油的特征波段主要集中在 C-H 键和 O-H 键区域（如 930nm, 1220nm, 1400nm 等）**。您在运行算法后，应检查筛选出的波长是否落在油脂特征区（近红外通常在 1200nm, 1400nm, 1700nm 附近）。

#### 第四步：可视化（谨慎使用）

**论文图 4 展示了单颗种子的含油率分布伪彩色图 。

* **您的局限** ：因为您只有一个“平均真值”，您训练出的模型是基于“平均光谱”的。
* **如何做** ：模型训练好之后，您可以将图像中的**每一个像素**的光谱代入模型，计算出一个预测值，生成伪彩色图。
* **改进解释** ：这张图 **只能用于定性分析** （例如看哪一颗花椒颜色偏红，代表含油高），但无法验证具体某一颗的数值是否准确，因为您没有单颗的真值。

### 3. 总结建议的实验流程

| **步骤**     | **论文方法 (油茶籽)**   | **您的改进方法 (花椒)**  | **原因**                |
| ------------------ | ----------------------------- | ------------------------------ | ----------------------------- |
| **输入**     | 单粒种子图像                  | 多粒堆积图像                   | 样本形态不同                  |
| **ROI**      | 提取单体                      | **提取所有颗粒并求平均** | 必须匹配“批量理化值”        |
| **预处理**   | Raw/SNV/MSC 对比              | **重点测试 SNV/MSC**     | 花椒表面散射严重              |
| **建模**     | PLSR + GA/CARS                | **PLSR + CARS**(推荐)    | CARS 运算更快，适合高维数据   |
| **异常剔除** | **MCCV (蒙特卡洛)**^10^ | **MCCV + 像素级清洗**    | 需剔除花椒表面的高光/阴影噪声 |

# 花椒含油量测量实现方案与计划

## 改进思路评估与补充建议

- 标签口径需统一：蒸馏量（ml）已知且有重量，统一换算为 `挥发油密度假定≈1 → ml ≈ g`，用 `ml/g` 或 `ml/100g` 作为主标签；保留原始蒸馏量与重量，必要时以重量和颗粒数作协变量，避免模型学习到“样本数量”而非含油率。
- ROI 需更稳健：在光谱掩膜基础上，加上形态学闭/开操作去除托盘边缘与椒梗；对极亮/极暗像素用分位数阈值（如 1%–99%）和局部均值过滤，减少固定阈值带来的批次差异；额外输出每盘的像素数量、面积占比，作为数据质量指标。
- 聚合方式可增强：除了全局均值，增加中位数、trimmed mean、标准差/偏度等统计量，或分块（tile）取若干子区求均值后再平均，捕捉花椒间的异质性，缓解单一均值对高光/阴影的敏感。
- 波段管理要依赖 hdr：按实际 hdr 波段剔除噪声端（两端约 10–20 个波段）及水吸收区（如 1350–1450、1800–1950 nm，如果覆盖到）；保留配置化的“有效波段清单”便于不同仪器切换。
- 预处理组合需扩展：在 SNV/MSC 基础上系统对比 SG+一阶导、去趋势（Detrend）、以及 SNV+一阶导组合；若批次差异大，可增加 ESC 或标准化至参考批次（PDS/DS）。
- 验证策略需加强：样本量有限时采用重复 K 折或留一交叉验证，避免以像素为单位划分；用 bootstrap 估计置信区间，并保留每次切分的随机种子，确保可重复。
- 模型与选择器：PLSR 作为主线，同时比较 CARS 与 GA；若特征数量仍多，可用 Lasso/ElasticNet 做稀疏基线；用 permutation importance 检验选出的波长是否稳定，防止偶然相关。

## 基于真实花椒数据的完整实现方案

- 数据解析与元数据统一：读取 `/home/yr/yr/data/科研数据/云南藤椒1-1/*/REFLECTANCE_*.hdr/dat`，结合 `docs/2025年8月花椒挥发油测定结果.xls` 提取样本编号、蒸馏量、重量（g）、日期，计算标准化标签 `oil_ml_per_gram = 蒸馏量 / 重量`，保留原值并生成 `data/processed/huajiao_metadata.parquet`，确保编号规则（0164_11 ↔ 0164-11）统一。
- ROI 与光谱聚合：按 hdr 波段计算光谱指数分割花椒与背景，形态学清理后在掩膜内做分位数过滤；生成全局均值、中位数、trimmed mean、标准差等聚合光谱，输出至 `data/processed/huajiao_spectra.parquet`，并记录像素数、掩膜比例以供质控。
- 光谱预处理：基于配置化波段裁剪，分别跑 Raw、SNV、MSC、SG+一阶导、Detrend、SNV+导数等管线；所有预处理在 `src/oil_content_detection/preprocessing/` 下以可组合的函数实现，参数（窗口、阶数）写入 `config/*.yaml`。
- 特征选择与建模：以样本级聚合光谱为 X、标准化标签 `oil_ml_per_gram` 为主 y，蒸馏量与重量可作为附加协变量或用于敏感性分析。运行全波段 PLSR 作为基线；在此基础上对每个预处理结果跑 CARS、GA，得到子波段，再训练 PLSR/Lasso/ElasticNet，记录 R²、RMSECV、RMSEP。交叉验证使用重复 K 折（如 5×5），并保留随机种子。
- 可视化与解释：输出波长重要性条形图、实际 vs 预测散点、残差分布；在单个样本上用最佳模型生成像素级伪彩色图用于定性展示，并附带掩膜覆盖率与异常像素比例。
- 产出物：模型及选择的波长列表、训练日志（CSV/JSON）、关键图表（PNG）、以及复现实验记录写入 `docs/实验记录/花椒/`；大体积数据不入库，仅保留元数据与可复用脚本。

#### **步骤 10：基线模型训练（全波段PLSR，约1小时）**

不做任何波长选择，直接用所有波长训练PLSR：

```python
import pandas as pd
import numpy as np
from sklearn.cross_decomposition import PLSRegression
from sklearn.model_selection import cross_val_score
from sklearn.metrics import r2_score, mean_squared_error

# 加载数据
train = pd.read_parquet("data/processed/huajiao/train/huajiao_spectra.parquet")
val = pd.read_parquet("data/processed/huajiao/val/huajiao_spectra.parquet")

# 提取特征和标签
wl_cols = [c for c in train.columns if c.startswith('wl_')]
X_train = train[wl_cols].values
y_train = train['oil_ml_per_gram'].values
X_val = val[wl_cols].values
y_val = val['oil_ml_per_gram'].values

# 网格搜索最佳成分数
print("寻找最佳PLSR成分数:")
for n_comp in range(1, min(21, len(X_train))):
    plsr = PLSRegression(n_components=n_comp)
    scores = cross_val_score(plsr, X_train, y_train, cv=5, scoring='r2')
    print(f"n_components={n_comp:2d}: CV R²={scores.mean():.4f} ± {scores.std():.4f}")

# 训练最佳模型
best_n = 10  # 根据上面的结果选择
plsr = PLSRegression(n_components=best_n)
plsr.fit(X_train, y_train)

# 评估
y_train_pred = plsr.predict(X_train)
y_val_pred = plsr.predict(X_val)

train_r2 = r2_score(y_train, y_train_pred)
val_r2 = r2_score(y_val, y_val_pred)
train_rmse = np.sqrt(mean_squared_error(y_train, y_train_pred))
val_rmse = np.sqrt(mean_squared_error(y_val, y_val_pred))

print(f"\n基线模型（全波段PLSR）:")
print(f"Train R²: {train_r2:.4f}, RMSE: {train_rmse:.4f}")
print(f"Val R²: {val_r2:.4f}, RMSE: {val_rmse:.4f}")
```

**预期结果**：
- 训练集R² > 0.80
- 验证集R² > 0.70

**如果结果不理想**：
- 检查标签质量（是否有录入错误）
- 检查光谱质量（是否有异常曲线）
- 检查样本量是否太少（可能需要更多数据）

使用遗传算法筛选关键波长：

```python
from oil_content_detection.feature_selection.ga_selector import GeneticAlgorithmSelector, GAConfig

# 对预处理后的数据应用GA

    generations=20,
    population_size=12,
    min_features=8,
    max_features=30,
    target_features=18,

# 获取选中的波长
selected_indices = ga.support_

# 用选中的波长训练PLSR
X_train_selected = X_train_preprocessed[:, selected_indices]
X_val_selected = X_val_preprocessed[:, selected_indices]

y_val_pred_ga = plsr_ga.predict(X_val_selected)

print(f"\nGA + PLSR:")
```

**重复K折交叉验证**：
```python
from sklearn.model_selection import RepeatedKFold

rkf = RepeatedKFold(n_splits=5, n_repeats=5, random_state=2024)
scores = []

for train_idx, val_idx in rkf.split(X_train_selected):
    X_t, X_v = X_train_selected[train_idx], X_train_selected[val_idx]
    y_t, y_v = y_train[train_idx], y_train[val_idx]

    model = PLSRegression(n_components=best_n)
    model.fit(X_t, y_t)
    score = model.score(X_v, y_v)
    scores.append(score)

print(f"重复5折交叉验证 (5次):")
print(f"R² = {np.mean(scores):.4f} ± {np.std(scores):.4f}")
print(f"R²范围: [{np.min(scores):.4f}, {np.max(scores):.4f}]")
```

### 问题1：ROI分割尺寸不一致 ⚠️ **已解决**

**现象**：

   - 支持可选缩放（`max_width`参数）
   - 纯HSV分割，无边界裁剪、模糊、形态学操作

2. 修改`generate_roi_masks.py`：
   - 默认`--hsv-max-width 0`（在原始尺寸上分割）
   - 输出`*_mask.png`（二值掩膜）和`*_overlay.png`（可视化）

3. 修改`build_huajiao_from_split.py`：
   - 优先加载预生成的掩膜（`--roi-mask-dir`）
   - 支持实时HSV分割作为备选

**使用流程**：
```bash
# 步骤1：调参（可选缩放，快速预览）
```

### 问题2：GA过拟合（最严重问题）⚠️ **已解决**

**现象**：
- 初始GA+PLSR: Train R²=0.9439, Val R²=0.3268（严重过拟合）
- 模型在训练集上表现优异，验证集上完全失效

**根本原因**：
1. **样本量过小**：仅39个训练样本
2. **特征数过多**：GA选择了30个波长（达到上限）
3. **PLSR成分过多**：使用了9个成分（30个特征的30%）
4. **交叉验证不稳定**：3折CV在小样本上方差大

**详细分析**：
```
初始GA配置（导致过拟合）：
- max_features: 30
- target_features: 18
- cv_splits: 3
- n_components: min(10, features//2) = 9（对于30个特征）

结果：
- 选中30个波长
- 使用9个PLSR成分
- 模型复杂度过高（39样本，9维空间）→ 过拟合
```

**解决方案（小样本优化策略）**：

1. **限制特征数**：
   ```python
   max_features=12        # 从30降至12
   target_features=10     # 从18降至10
   min_features=6         # 从8降至6
   ```

2. **增强交叉验证**：
   ```python
   cv_splits=5            # 从3增至5
   patience=5             # 从4增至5（早停耐心）
   ```

3. **限制PLSR复杂度**：
   ```python
   # 原来：min(10, features//2)
   # 现在：min(6, features//2)
   max_comp = min(6, len(X_train)-1, len(selected_indices)//2)
   ```

4. **增加种群多样性**：
   ```python
   population_size=16     # 从12增至16
   mutation_rate=0.08     # 从0.04增至0.08
   elite_count=2          # 从1增至2
   ```

**效果对比**：

| 配置 | 特征数 | 成分数 | Train R² | Val R² | 状态 |
|------|--------|--------|----------|--------|------|
| 初始配置 | 30 | 9 | 0.9439 | 0.3268 | ❌ 严重过拟合 |
| 优化配置 | 12 | 5 | 0.7988 | **0.9163** | ✅ 优异 |

### 脚本2：GA特征选择（内联Python）

**功能**：运行优化后的GA+PLSR流程

**运行方式**：
```bash
/home/yr/anaconda3/envs/hj/bin/python - <<'PY'
import sys
sys.path.insert(0, 'src')

import numpy as np
import pandas as pd
from scipy.signal import savgol_filter
from sklearn.cross_decomposition import PLSRegression
from sklearn.model_selection import cross_val_score
from sklearn.metrics import r2_score, mean_squared_error
from oil_content_detection.feature_selection.ga_selector import GeneticAlgorithmSelector, GAConfig

# 加载数据
train = pd.read_parquet("data/processed/huajiao/train/huajiao_spectra.parquet")
val = pd.read_parquet("data/processed/huajiao/val/huajiao_spectra.parquet")

wl_cols = [c for c in train.columns if c.startswith('wl_')]
wavelengths = np.array([float(c.split('_')[1]) for c in wl_cols])

X_train = train[wl_cols].values
y_train = train['oil_ml_per_gram'].values
X_val = val[wl_cols].values
y_val = val['oil_ml_per_gram'].values

# 应用SG一阶导
X_train_prep = savgol_filter(X_train, 9, 2, deriv=1, axis=1)
X_val_prep = savgol_filter(X_val, 9, 2, deriv=1, axis=1)

# 配置GA
ga_config = GAConfig(
    generations=15, population_size=16,
    min_features=6, max_features=12, target_features=10,
    mutation_rate=0.08, crossover_rate=0.85,
    elite_count=2, patience=5, cv_splits=5,
    verbose=True, random_state=2024
)

# 运行GA
ga = GeneticAlgorithmSelector(config=ga_config)
ga.fit(X_train_prep, y_train)

support = ga.get_support()
selected_indices = np.where(support)[0]
selected_wavelengths = wavelengths[selected_indices]

print(f"选中 {len(selected_wavelengths)} 个波长: {selected_wavelengths}")

# 训练PLSR
X_train_sel = X_train_prep[:, selected_indices]
X_val_sel = X_val_prep[:, selected_indices]

max_comp = min(6, len(X_train)-1, len(selected_indices)//2)
best_r2, best_n = -1, 1
for n in range(1, max_comp+1):
    cv_r2 = cross_val_score(PLSRegression(n_components=n, scale=False),
                           X_train_sel, y_train, cv=5, scoring='r2').mean()
    if cv_r2 > best_r2:
        best_r2, best_n = cv_r2, n

plsr = PLSRegression(n_components=best_n, scale=False)
plsr.fit(X_train_sel, y_train)

y_val_pred = plsr.predict(X_val_sel).ravel()
val_r2 = r2_score(y_val, y_val_pred)
val_rmse = np.sqrt(mean_squared_error(y_val, y_val_pred))

print(f"\n最终模型：")
print(f"  波长数: {len(selected_wavelengths)}")
print(f"  PLSR成分: {best_n}")
print(f"  Val R²: {val_r2:.4f}")
print(f"  RMSEP: {val_rmse:.6f}")
PY
```

## 经验总结与最佳实践

1. **小样本建模原则**：
   - 特征数应 < 样本数的1/3
   - PLSR成分数应 < min(样本数/5, 特征数/2)
   - 使用5折或更多折交叉验证
   - 保留足够的验证集（至少20%）

2. **ROI提取流程**：
   - 先在缩放图像上调参（快速）
   - 再在原始尺寸上批量生成掩膜（准确）
   - 必须人工检查所有overlay图像
   - 使用预生成mask而非实时分割

3. **预处理选择**：
   - 对于粗糙表面（如花椒），优先尝试导数变换
   - SNV/MSC可能导致过拟合（Train R²很高但Val R²低）
   - 原始数据+简单预处理往往更稳健

4. **GA参数调优**：
   - 从保守参数开始（小max_features）
   - 观察Train R² vs Val R²的差距
   - 如果过拟合，降低复杂度；如果欠拟合，增加复杂度
   - 多次运行验证波长稳定性

## 常见问题与解决方案（原版，供参考）

### 问题1：ROI覆盖率太低（原版）
**原因**：HSV阈值不合适
**解决**：返回步骤2重新调参，或调整像素清洗阈值

### 问题2：模型R²很低（<0.50）
**原因**：标签质量差、光谱质量差、或样本量太少
**解决**：
1. 检查标签录入是否有误
2. 检查光谱曲线是否正常
3. 尝试不同的预处理方法

### 问题3：训练集R²高但验证集R²低（过拟合）
**原因**：模型复杂度太高
**解决**：
1. 减少PLSR成分数
2. 增加GA选择的波长数量限制
3. 增加训练样本

### 问题4：GA选出的波长不合理
**原因**：GA陷入局部最优
**解决**：
1. 增加种群数和代数
2. 多次运行取稳定的波长
3. 手动检查选中波长是否在油脂特征区
