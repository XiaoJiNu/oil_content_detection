# 油茶籽含油率复现计划

## 1. 目标与预期成果

- 复现《基于高光谱成像的油茶籽含油率检测方法》中的实验流程，重建400–1 000 nm与900–1 700 nm双波段采集、变量筛选与PLSR建模。
- 输出高光谱数据处理管线、模型性能对照（R²、RMSEP、RMSECV）及含油率伪彩色可视化结果。
- 形成可复用的代码框架、数据管理规范与实验记录，支撑后续算法改进。

## 2. 数据资源与采集计划

- 已有资料：论文全文、需求文档；暂缺原始光谱数据与含油率实测值。
- 原始数据采集：规划两套系统（Spectral Set Ⅰ：400–1 000 nm；Set Ⅱ：900–1 700 nm）。按照论文参数设置：
  - Set Ⅰ：距样品300 mm，曝光1.2 ms，位移台0.6014 mm/s，分辨率800×664，扫描长度200 mm。
  - Set Ⅱ：距样品300 mm，曝光7.5 ms，位移台2.2568 mm/s，分辨率640×542，扫描长度200 mm。
- 样本准备：采集至少109颗油茶果，记录形态参数，次日剥壳取籽；逐粒采三颗取平均光谱。
- 含油率标定：使用NAI ZFCDY 6Z索氏抽提仪，按GB 5009.6—2016执行；每粒质量约2 g，抽提6 h，干燥称量后计算含油率。

## 3. 实验流程

1. **系统标定**：采集白板与暗场图像，按公式 `Re = (R0 - D)/(W - D)`完成黑白校正；剔除噪声波段（SetⅠ保留416.6–994.9 nm，SetⅡ保留1038.3–1564.9 nm）。
2. **ROI提取与数据整理**：对每颗籽获取ROI平均光谱；将光谱与含油率、采样元信息写入统一数据表（CSV/Parquet）。
3. **异常样本检测**：Monte Carlo交叉验证（5000次、训练/预测=2∶1）筛除异常样本，目标保留约102份。
4. **预处理对比**：实现原始、MSC、SNV、SG、Normalize、Detrend六条管线，基于PLSR评估潜变量数（最小RMSECV）。
5. **特征波长筛选**：复现SPA、CARS、PSO、ACO、SA、iRF、GA；采用论文参数（如GA：代数150、种群64、变异率1%；PSO：种群20、迭代1000，F=R²；ACO：蚁群30、迭代100、窗口1，F=(1+QRMSECV)/R²等），输出各自特征波段。
6. **模型训练与评估**：对全波段与筛选波段分别训练PLSR；记录R²c、R²p、RMSEC、RMSEP、RMSECV；重点验证SetⅡ + GA组合。
7. **可视化复现**：将最佳模型应用至高光谱立方体，生成含油率伪彩色图，分析边缘误差并与论文图4对照。
8. **结果汇总**：撰写实验记录（含数据分布、模型指标、误差分析），提供再现性说明。

## 4. 工具与环境

- 硬件：双波段高光谱成像系统、电控位移台、标准白板、索氏抽提装置、恒温干燥箱。
- 软件：ENVI或SpectralPython处理原始立方体；Python 3.10+（numpy、scipy、pandas、scikit-learn、matplotlib、spectral、pykrige）实现算法；备选Matlab脚本以对照。
- 版本控制：Git记录代码与实验配置；数据存于 `data/raw`、`data/processed`分层，>50 MB文件外部存储并以元数据链接。

## 5. 时间与任务拆分（参考）

## 6. 风险与应对

- **数据缺失**：若无法立即获取原始光谱，先使用公开近红外数据进行算法验证，再迁移至实测数据。
- **算法复现难度**：优先使用论文参数，必要时查阅原作者参考文献；全部实现统一接口便于调试。
- **设备差异**：记录实际设备参数，必要时重新优化曝光与扫描速度；对比论文指标时注明差异。
- **模型泛化**：引入交叉验证与留一法评估稳定性；必要时增加正则化或多模型融合。

# 针对花椒含油量测量的改进思路

我现在要将《基于高光谱成像的油茶籽含油率检测方法》这个方法用于花椒的含油量检测，但是花椒的样本采集与论文中不太一样，所以需要专门进行改进。

## 数据情况

如docs/reference_docs/功能需求文档/20251118需求整理/0164_11.jpg这个图片所示，花椒含油量的一个样本是多颗花椒一起用光谱扫描，得到了光谱扫描数据，且数据已经经过黑白校正。

每个样本对应一个编号，以一个样本编号0164_11为例进行说明：

**扫描的光谱数据**：数据整体目录结构如docs/reference_docs/功能需求文档/20251118需求整理/一个样本数据的目录结构_整体.png所示，路径/home/yr/yr/data/科研数据/云南藤椒1-1/0164_11，其中0164_11是最外层目录名字。实际的光谱数据是docs/reference_docs/功能需求文档/20251118需求整理/一个样本数据的目录结构_实际数据.png中的REFLECTANCE_0164_11.dat和REFLECTANCE_0164_11.hdr。这是经过黑白校正后的数据。

对应的花椒图片为docs/reference_docs/功能需求文档/20251118需求整理/0164_11.jpg

**含油量数据**：在docs/2025年8月花椒挥发油测定结果.xls中，如图docs/reference_docs/功能需求文档/20251118需求整理/含油量数据.png所示，它对应高光谱图件编号0164-11那一行，蒸馏量（初）ml为0.5。

## 改进思路1

现在的实验数据是"一幅包含多粒花椒的图像对应一个含油量真值”**（即群体平均值对应群体光谱），那么论文中的核心算法流程（PLSR建模、特征波长筛选）是完全可用的，但在**数据预处理**和**ROI（感兴趣区域）提取**这两个环节需要针对花椒数据特性做重要的**逻辑修正**。

以下是改进方案：

### 1. 核心逻辑的转变：从“单体”到“群体”

论文的研究对象是**单颗**油茶籽，其流程是：提取单颗籽的平均光谱 **$\rightarrow$** 对应单颗籽的理化值 。

您的情况是群体花椒，您的流程必须调整为：

提取图中所有花椒像素的平均光谱 $\rightarrow$ 对应这一盘花椒的理化总值。

如果您试图分割出每一颗单独的花椒，因为您没有每一颗单独的含油率数据，强行将总含油率赋给每一颗花椒作为标签（Label）去训练，会引入巨大的标签噪声，导致模型失败。

---

### 2. 具体改进步骤

#### 第一步：ROI 提取策略（关键修正）

论文中通过图像分割提取了单颗种子的ROI。对于您的多粒花椒图像：

* **原来的做法（论文）** ：提取整个种子的区域。
* **您的改进做法** ：

1. **二值化掩膜（Mask）** ：利用阈值法或波段运算（如 **$R_{800nm} / R_{650nm}$**）生成一个掩膜，将所有花椒颗粒与背景（托盘）分离。
   备注：这里的掩膜方法先采用传统方法，后面可以考虑用深度学习。
2. **像素清洗** ：花椒表面皱缩严重，会产生 **高光点** （过曝）和 **阴影深坑** （欠曝）。这些像素是噪声。建议在掩膜内进一步剔除反射率过高（>0.9）或过低（<0.05）的异常像素。
   备注：是否需要剔除，需要评估
3. **空间平均（Spatial Average）** ：将掩膜内**所有**保留下来的花椒像素的光谱求平均值。

* **结果** ：您的一张图最终只生成**一条**平均光谱曲线，这条曲线代表了这盘花椒的整体特征，正好与您的理化值对应。

#### 第二步：光谱预处理（针对性加强）

**论文中提到对于油茶籽，未经预处理的原始数据（Raw Data）在某些波段下效果最好 **^3^。但这对花椒可能不适用。

* **差异点** ：油茶籽相对圆润，花椒表面极其粗糙，光散射效应（Scattering Effect）极其严重。
* **改进建议** ：
* 不要直接信赖原始数据。
* **强制尝试 SNV（标准正态变量变换）和 MSC（多元散射校正）** **。论文中对比了 SNV 和 MSC ，这两种方法专门用于消除颗粒表面不平整导致的物理光程差异，对花椒这种物料是必须的。
* **导数处理** **：尝试一阶导数（SG平滑后求导）**，有助于提取油脂在特定波段的吸收峰，减弱背景基线干扰。

#### 第三步：特征波长选择（复用论文方法）

**论文比较了 SPA、CARS、PSO、ACO、SA、iRF、GA 等七种方法 。结论是 **GA（遗传算法）** 和 **CARS** 表现较好 。

* **直接应用** ：这一步不需要改。您使用计算出的“群体平均光谱”作为输入 **$X$**，含油量作为 **$Y$**，直接运行论文中提到的 CARS 或 GA 算法。
* **注意** **：花椒油（挥发油）和籽油的特征波段可能不同。论文中油茶籽油的特征波段主要集中在 C-H 键和 O-H 键区域（如 930nm, 1220nm, 1400nm 等）**。您在运行算法后，应检查筛选出的波长是否落在油脂特征区（近红外通常在 1200nm, 1400nm, 1700nm 附近）。

#### 第四步：可视化（谨慎使用）

**论文图 4 展示了单颗种子的含油率分布伪彩色图 。

* **您的局限** ：因为您只有一个“平均真值”，您训练出的模型是基于“平均光谱”的。
* **如何做** ：模型训练好之后，您可以将图像中的**每一个像素**的光谱代入模型，计算出一个预测值，生成伪彩色图。
* **改进解释** ：这张图 **只能用于定性分析** （例如看哪一颗花椒颜色偏红，代表含油高），但无法验证具体某一颗的数值是否准确，因为您没有单颗的真值。

---

### 3. 总结建议的实验流程

| **步骤**     | **论文方法 (油茶籽)**   | **您的改进方法 (花椒)**  | **原因**                |
| ------------------ | ----------------------------- | ------------------------------ | ----------------------------- |
| **输入**     | 单粒种子图像                  | 多粒堆积图像                   | 样本形态不同                  |
| **ROI**      | 提取单体                      | **提取所有颗粒并求平均** | 必须匹配“批量理化值”        |
| **预处理**   | Raw/SNV/MSC 对比              | **重点测试 SNV/MSC**     | 花椒表面散射严重              |
| **建模**     | PLSR + GA/CARS                | **PLSR + CARS**(推荐)    | CARS 运算更快，适合高维数据   |
| **异常剔除** | **MCCV (蒙特卡洛)**^10^ | **MCCV + 像素级清洗**    | 需剔除花椒表面的高光/阴影噪声 |

# 花椒含油量测量实现方案与计划

## 改进思路评估与补充建议

- 标签口径需统一：蒸馏量（ml）已知且有重量，统一换算为 `挥发油密度假定≈1 → ml ≈ g`，用 `ml/g` 或 `ml/100g` 作为主标签；保留原始蒸馏量与重量，必要时以重量和颗粒数作协变量，避免模型学习到“样本数量”而非含油率。
- ROI 需更稳健：在光谱掩膜基础上，加上形态学闭/开操作去除托盘边缘与椒梗；对极亮/极暗像素用分位数阈值（如 1%–99%）和局部均值过滤，减少固定阈值带来的批次差异；额外输出每盘的像素数量、面积占比，作为数据质量指标。
- 聚合方式可增强：除了全局均值，增加中位数、trimmed mean、标准差/偏度等统计量，或分块（tile）取若干子区求均值后再平均，捕捉花椒间的异质性，缓解单一均值对高光/阴影的敏感。
- 波段管理要依赖 hdr：按实际 hdr 波段剔除噪声端（两端约 10–20 个波段）及水吸收区（如 1350–1450、1800–1950 nm，如果覆盖到）；保留配置化的“有效波段清单”便于不同仪器切换。
- 预处理组合需扩展：在 SNV/MSC 基础上系统对比 SG+一阶导、去趋势（Detrend）、以及 SNV+一阶导组合；若批次差异大，可增加 ESC 或标准化至参考批次（PDS/DS）。
- 验证策略需加强：样本量有限时采用重复 K 折或留一交叉验证，避免以像素为单位划分；用 bootstrap 估计置信区间，并保留每次切分的随机种子，确保可重复。
- 模型与选择器：PLSR 作为主线，同时比较 CARS 与 GA；若特征数量仍多，可用 Lasso/ElasticNet 做稀疏基线；用 permutation importance 检验选出的波长是否稳定，防止偶然相关。

## 基于真实花椒数据的完整实现方案

- 数据解析与元数据统一：读取 `/home/yr/yr/data/科研数据/云南藤椒1-1/*/REFLECTANCE_*.hdr/dat`，结合 `docs/2025年8月花椒挥发油测定结果.xls` 提取样本编号、蒸馏量、重量（g）、日期，计算标准化标签 `oil_ml_per_gram = 蒸馏量 / 重量`，保留原值并生成 `data/processed/huajiao_metadata.parquet`，确保编号规则（0164_11 ↔ 0164-11）统一。
- ROI 与光谱聚合：按 hdr 波段计算光谱指数分割花椒与背景，形态学清理后在掩膜内做分位数过滤；生成全局均值、中位数、trimmed mean、标准差等聚合光谱，输出至 `data/processed/huajiao_spectra.parquet`，并记录像素数、掩膜比例以供质控。
- 光谱预处理：基于配置化波段裁剪，分别跑 Raw、SNV、MSC、SG+一阶导、Detrend、SNV+导数等管线；所有预处理在 `src/oil_content_detection/preprocessing/` 下以可组合的函数实现，参数（窗口、阶数）写入 `config/*.yaml`。
- 特征选择与建模：以样本级聚合光谱为 X、标准化标签 `oil_ml_per_gram` 为主 y，蒸馏量与重量可作为附加协变量或用于敏感性分析。运行全波段 PLSR 作为基线；在此基础上对每个预处理结果跑 CARS、GA，得到子波段，再训练 PLSR/Lasso/ElasticNet，记录 R²、RMSECV、RMSEP。交叉验证使用重复 K 折（如 5×5），并保留随机种子。
- 可视化与解释：输出波长重要性条形图、实际 vs 预测散点、残差分布；在单个样本上用最佳模型生成像素级伪彩色图用于定性展示，并附带掩膜覆盖率与异常像素比例。
- 产出物：模型及选择的波长列表、训练日志（CSV/JSON）、关键图表（PNG）、以及复现实验记录写入 `docs/实验记录/花椒/`；大体积数据不入库，仅保留元数据与可复用脚本。
