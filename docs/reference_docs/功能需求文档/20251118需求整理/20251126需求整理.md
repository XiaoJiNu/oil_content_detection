# 训练与优化

## 优化1

### 背景

 目前的结果,R^2比较低.我分析可能是分析的花椒的ROI中,有一些花椒的缝隙被连接在一起了,导致最终生成的数据中,包含了一些背景的光谱数据,导致结果不准确.有2种解决思
  路

1. 进一步优化花椒的分割,让分割结果更准确,减少背景的干扰
2. 分析背景的光谱数据,它应该和花椒的数据有，区别，那么,在生成特征数据时,将背景占的光谱数据剔除,这样就能减少背景干扰
3. 进一步优化模型.
   给出你的建议方案

• 我建议按“先证伪/证实 → 低成本强约束 → 再做复杂优化”的顺序来做，优先级是 2 > 1 > 3。

- 先验证你的判断（必须做）：对每个样本计算“疑似背景占比”（例如 manual_mask & ~refined_mask 的像素占 manual 的比例、refined_mask 的覆盖率/像素数），再把它和
  验证集残差做相关分析/分箱对比；如果“背景占比越高误差越大”，就基本坐实是 ROI 污染主因。
- 方案2（优先落地，收益/成本最高）：在生成特征表时，用高光谱在 ROI 内再做一次“光谱域剔除背景”，把 refined_mask ∩ spectral_mask 作为最终 ROI。
  - spectral_mask 可以先用简单鲁棒的阈值（如 NIR/Red 比值 + 强度阈值/分位数），或在每张图内做 2 类聚类（KMeans/GMM）用光谱把“花椒 vs 红纸背景”分开。
  - 同时输出每个样本的“最终有效像素数/占比”做 QC，过小直接标记为异常样本。
- 方案1（作为补充，不建议先做重调参）：灰度 Otsu 后的形态学很可能“闭运算把缝隙桥接了”，建议方向是减少桥接：减小/移除大核闭运算、以开运算断开细连接、只填“小
  孔洞”（限制 hole area），避免把“颗粒间背景”填进去。
- 方案3（最后做）：在 ROI 纯度提升后再系统调模型，否则容易把噪声拟合进去。建议做：预处理组合（Raw/SNV/MSC/SG1）、目标变换（log/Box-Cox）、更稳健评估（重复
  KFold/按批次 group split），再考虑非线性模型（SVR/RF）对比。

## 20260105 优化方案 (基于论文与搜索)

### 背景

目前基线模型 `Raw + GA + PLSR` 在验证集上达到 $R^2 \approx 0.7509$，MAE $\approx 0.1974$。误差分析显示模型在不同品种和批次间存在偏差（如“回归均值”现象），且线性模型（PLSR）可能已接近性能瓶颈。文献调研（如 *Zanthoxylum bungeanum* volatile oil prediction）表明，针对花椒这类复杂农产品，非线性模型（如 SVR）结合高效特征选择（如 CARS），以及深度学习（1D-CNN）是提升精度的有效途径。

### 方案一：CARS + SVR (文献推荐的主流非线性方案)

**原理**：

* **CARS (Competitive Adaptive Reweighted Sampling)**：相比 GA，CARS 通过模拟“适者生存”原则（指数衰减 + 自适应重加权）筛选特征，通常能选出更精简且稳定的波段子集，在多篇花椒/食品检测论文中表现优于 GA。
* **SVR (Support Vector Regression)**：利用核函数（RBF）映射到高维空间解决非线性问题，适合处理花椒含油量与光谱间的复杂非线性关系。

**实施细节**：

1. **特征选择**：实现 CARS 算法，替代 GA 进行波段筛选。
2. **预处理组合**：SVR 对尺度敏感，必须尝试 `SNV/MSC` + `StandardScaler`（列标准化）。
3. **参数优化**：使用 `Optuna` 或 `GridSearch` 联合优化 SVR 的关键参数 $(C, \gamma, \epsilon)$ 和 CARS 的主成分数。
4. **预期效果**：解决 PLSR 欠拟合问题，提升对高/低含油量样本的预测能力。

### 方案二：1D-CNN + Mixup 数据增强 (深度学习方案)

**原理**：

* **1D-CNN**：利用卷积核自动提取光谱的局部特征（如吸收峰的形状、斜率），比全连接层更适合连续光谱数据。
* **Mixup / Noise Injection**：针对本项目样本少（Train=157）的痛点，通过混合样本 $(x = \lambda x_i + (1-\lambda)x_j, y = \lambda y_i + (1-\lambda)y_j)$ 和注入高斯噪声，扩充训练数据，平滑模型决策边界，防止过拟合。

**实施细节**：

1. **网络架构**：设计轻量级 1D-CNN（Input -> Conv1D -> BatchNorm -> ReLU -> MaxPool -> Conv1D -> ... -> GlobalAvgPool -> Dense -> Output）。
2. **数据增强**：
   * **Mixup**：在 Batch 训练时动态混合样本。
   * **Spectral Shift/Scale**：模拟光照变化。
3. **训练策略**：使用 AdamW 优化器，结合 CosineAnnealing 学习率调度，Early Stopping 防止过拟合。

### 方案三：集成学习 (Ensemble Learning)

**原理**：

* 利用 `XGBoost`、`LightGBM` 或 `CatBoost` 的梯度提升树模型。这些模型在处理表格型/结构化数据（光谱波段可视为特征列）时往往优于单一线性模型，且自带特征重要性评估。

**建议执行顺序**：

1. **优先执行 方案一 (CARS + SVR)**：这是文献中针对花椒油含量检测最成功的方案，且实现成本相对可控，解释性优于深度学习。
2. **其次执行 方案二 (1D-CNN)**：如果 SVR 仍无法突破 0.8 的 $R^2$，则尝试深度学习挖掘深层特征。

## 优化2-SVR模型下的方案

#### 目标

在保持当前数据处理与 ROI 精细化流程不变（`data/processed/huajiao_refined/{train,val}`）的前提下，针对 **PLSR 线性上限**，引入 **CARS 特征选择 + SVR（RBF）非线性回归**，提升跨品种/跨批次的泛化能力与验证集指标。

#### 方案概览（CARS + SVR）

1. **预处理（建议组合对比）**

   * 目标：消除散射/基线漂移带来的非化学成分差异，提高模型可迁移性。
   * 预处理候选（按常见顺序）：
     1) `snv` 或 `msc`（优先二选一）
     2) 可选 `sg`（平滑）或 `sg1`（一阶导）
     3) **列标准化**：在 SVR 前增加 `StandardScaler`（SNV/MSC 是逐样本归一化，SVR 往往仍受各波段尺度影响）
2. **特征选择：CARS（Competitive Adaptive Reweighted Sampling）**

   * 用途：相对 GA 更“稳定/快速”地筛选与含油率最相关的波段子集，降低噪声与过拟合风险。
   * 核心流程：
     * Monte-Carlo 抽样（每次用 ~80% 训练样本）
     * 用 PLSR 回归系数绝对值作为变量权重
     * EDF（指数衰减）逐步降低保留变量数
     * ARS（按权重采样/重加权）得到当前子集
     * CV 评估（RMSECV）选取最优子集，并保存全程 history（便于复现与诊断）
   * 建议初始参数（可按训练集规模微调）：
     * `n_mc=50`、`sample_ratio=0.8`、`cv=5`
     * `pls_n_components=8`（或在内层 CV 内选）
     * 固定随机种子并保存 `cars_history.json`、`selected_wavelengths.json`
3. **回归模型：SVR（RBF）**

   * 原因：小样本、高维特征下，SVR（RBF）对非线性关系拟合能力更强，且常见于挥发油/含油量相关文献。
   * 调参策略：
     * 采用 **嵌套交叉验证** 或 “训练集 CV 搜参 + 固定验证集评估”的方式，避免调参泄漏。
     * 推荐优先 `RandomizedSearchCV`（更快）或小范围 `GridSearchCV`：
       * `C`：对数尺度（如 1e-1 ~ 1e4）
       * `gamma`：`'scale'` + 对数尺度（如 1e-6 ~ 1）
       * `epsilon`：如 `[0.005, 0.01, 0.02, 0.05, 0.1]`

    *   **稳定性修正**：针对预处理（如 SG1）后出现的低方差/常数波段，增加了自动移除（`std < 1e-8`）逻辑，并修正了 PLSR `scale=False` 以避免梯度爆炸。

2.  **实验结果（验证集 Val n=40）**

    *   **基线（Raw + GA + PLSR）**：$R^2 = 0.7509$
    *   **实验 1：CARS + PLSR (SNV + SG1)**：
        *   选定波段数：30
        *   验证集指标：$R^2 = 0.7258$，RMSE = 0.2360
        *   结论：CARS 在经过平滑预处理的数据上表现良好，接近 GA 基线，且波段选择更加自适应。
    *   **实验 2：CARS + SVR (SNV + SG1)**：
        *   选定波段数：30（同上）
        *   SVR 最优参：`C=12.74, epsilon=0.005, gamma='auto'`
        *   验证集指标：$R^2 = 0.6557$，RMSE = 0.2644
        *   结论：在 CARS 选出的特征子集（该子集由 PLSR 准则优化）上，SVR 未能超越 PLSR，可能存在特征不匹配或小样本过拟合。
    *   **实验 3：CARS + PLSR (Raw)**：
        *   验证集指标：$R^2 = 0.6345$
        *   结论：CARS 对噪声较敏感，未做 SNV/SG1 预处理时性能显著下降（这点与 GA 不同，GA 在 Raw 上表现最好）。

3.  **总结与建议**
    *   **CARS 有效性**：证明了 CARS 是一种有效的特征选择方法（$R^2 > 0.72$），特别是在配合预处理（SNV+SG1）时。
    *   **模型选择**：当前数据集上，**线性模型 (PLSR)** 依然表现最稳健（$R^2 \approx 0.75$）。SVR 的引入未带来直接提升，可能受限于样本量（157个训练样本）或特征选择方法的线性偏好。
