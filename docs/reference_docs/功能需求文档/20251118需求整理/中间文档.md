# 方案-gemini-灰度方案

## 背景与发现

**在之前的尝试中，我们利用 LAB 色彩空间和纹理特征成功找回了紫色花椒，但在处理缝隙和孔洞时面临形态学参数的权衡难题。**
**最新的观察发现：****在简单的灰度图（特别是经过 CLAHE 增强后）中，花椒颗粒与红纸背景呈现出显著的灰度差异**。这意味着我们可以回归到更本质、更鲁棒的**灰度阈值分割**算法，而非依赖复杂的色彩/纹理组合逻辑。

## 方案详情

### 1. 核心算法：CLAHE + Otsu

**新的分割流程极度简化且高效：**

1. **灰度转换**：将 ROI 区域内的图像转换为灰度图。
2. **CLAHE 增强**：应用自适应直方图均衡化（Contrast Limited Adaptive Histogram Equalization），显著增强花椒与背景的对比度，同时克服光照不均（暗光样本）的问题。
3. **Otsu 阈值分割**：在 ROI 区域内自动计算最佳灰度阈值，将图像分为“前景”和“背景”两类。
4. **极性自适应**：通过判断前景/背景的面积占比（假设背景面积 > 花椒面积），自动纠正掩膜的极性，确保“花椒”始终为前景（白色）。

### 2. 形态学与后处理（保留之前的优化成果）

**虽然核心分割变了，但之前针对缝隙和孔洞调整好的形态学策略依然适用：**

1. **形态学序列**：`初始闭运算(5) -> 开运算(5) -> 最终闭运算(5)`。
   * **填补内部噪点 -> 切断粘连缝隙 -> 平滑边缘。**
2. **显式填孔**：利用连通域分析填充 < 300 像素的内部空洞，确保花椒实心。
3. **连通域筛选**：剔除过小的噪点区域。

### 3. 方案优势

* **鲁棒性更强**：不再依赖“红色”或“绿色”的特定颜色阈值，对花椒颜色变化（绿/紫/黑）完全不敏感。
* **适应性更好**：CLAHE 天然适应暗光、亮光变化。
* **计算更简**：无需计算纹理图或多个色彩空间，速度更快。
