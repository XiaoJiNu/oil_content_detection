# 方案-gemini-灰度方案

## 背景与发现

**在之前的尝试中，我们利用 LAB 色彩空间和纹理特征成功找回了紫色花椒，但在处理缝隙和孔洞时面临形态学参数的权衡难题。**
**最新的观察发现：****在简单的灰度图（特别是经过 CLAHE 增强后）中，花椒颗粒与红纸背景呈现出显著的灰度差异**。这意味着我们可以回归到更本质、更鲁棒的**灰度阈值分割**算法，而非依赖复杂的色彩/纹理组合逻辑。

## 方案详情

### 1. 核心算法：CLAHE + Otsu

**新的分割流程极度简化且高效：**

1. **灰度转换**：将 ROI 区域内的图像转换为灰度图。
2. **CLAHE 增强**：应用自适应直方图均衡化（Contrast Limited Adaptive Histogram Equalization），显著增强花椒与背景的对比度，同时克服光照不均（暗光样本）的问题。
3. **Otsu 阈值分割**：在 ROI 区域内自动计算最佳灰度阈值，将图像分为“前景”和“背景”两类。
4. **极性自适应**：通过判断前景/背景的面积占比（假设背景面积 > 花椒面积），自动纠正掩膜的极性，确保“花椒”始终为前景（白色）。

### 2. 形态学与后处理（保留之前的优化成果）

**虽然核心分割变了，但之前针对缝隙和孔洞调整好的形态学策略依然适用：**

1. **形态学序列**：`初始闭运算(5) -> 开运算(5) -> 最终闭运算(5)`。
   * **填补内部噪点 -> 切断粘连缝隙 -> 平滑边缘。**
2. **显式填孔**：利用连通域分析填充 < 300 像素的内部空洞，确保花椒实心。
3. **连通域筛选**：剔除过小的噪点区域。

### 3. 方案优势

* **鲁棒性更强**：不再依赖“红色”或“绿色”的特定颜色阈值，对花椒颜色变化（绿/紫/黑）完全不敏感。
* **适应性更好**：CLAHE 天然适应暗光、亮光变化。
* **计算更简**：无需计算纹理图或多个色彩空间，速度更快。

### codex-分析与改进

#### 现象复盘

1. **当前训练管线**：
   * **脚本：**`scripts/train_huajiao_oil_content.py`
   * **数据：**`data/processed/huajiao_refined`（Train=157, Val=40）
   * **特征：ROI 内像素聚合光谱 **`wl_<nm>`（默认只用 `trimmed_mean` 主统计量），未使用 SG/SNV/MSC 等光谱预处理
   * **选择与建模：GA（5-Fold CV **`R²` + 特征数惩罚）选波段 + PLSR（`n_components=min(10, selected//2)` 启发式）
2. **结果特征**：
   * **Val：R²=0.7227，RMSE=0.2373**
   * **从 **`results/huajiao_refined_oil_content/val_predictions.csv` 看，预测方差有收缩（预测 std < 实测 std），对极端含油率样本呈现“回归均值”的欠拟合现象（低值被高估、高值被低估）。

#### 更可能的原因（按优先级）

1. **数据与标签噪声/异质性带来的上限**：
   * **split 覆盖多个品类/批次（**`data/labels/huajiao_2025_08_plus` 统计共有 33 个目录组），不同品类的基底光谱差异可能大于“油含量差异”本身，且挥发油蒸馏/读数/称量存在实验噪声，整体 R² 上限可能低于此前小样本实验（README/复现计划中的 39/10）。
2. **光谱特征表达不足（预处理缺失）**：
   * **既往基线对比（见 **`README.md` 与 `docs/reference_docs/功能需求文档/复现计划.md` 阶段二）显示：SG 一阶导对 R² 提升明显；当前训练直接用 Raw 反射率 + PLSR，油相关信号可能被散射、光照不均、厚度差异等因素淹没。
3. **可能存在 “mask → cube” 的空间对齐问题（需要验证）**：
   * `data/processed/ROI_visual_refined` 验证的是 RGB 图上的分割效果；构建特征时是将 mask resize 到高光谱 cube 上。若 RGB 图与 cube 存在旋转/镜像/裁剪差异，ROI 会混入背景光谱，直接拉低上限。
4. **波长列命名的舍入可能导致信息丢失（需要验证）**：
   * `huajiao_dataset._column_name` 使用 `int(round(wl))` 生成 `wl_<nm>`；若原始波长为非整数或间隔 < 1nm，可能出现列名重复并覆盖，导致部分波段信息被隐式丢弃。
5. **模型与超参可能偏保守/目标不一致**：
   * `n_components` 未做系统搜索，仅用启发式；同时 GA 的目标函数实际是 CV `R²`（带特征数惩罚），而脚本/文档里写的是 “RMSE”，存在表述不一致（不影响训练流程，但可能影响对当前配置的判断）。

#### 建议的排查与改进方案（先验证，再实现）

**A. 快速排查（低成本，优先做）**

1. **对齐验证**：抽样 10 个样本（尤其是 val 误差最大的若干样本），在 cube 的单波段或均值强度图上叠加“resize 后的 mask”，确认 ROI 是否与真实花椒区域一致；若不一致，优先修正对齐（flip/rotate/offset），再谈模型。
2. **波长重复/覆盖检查**：核对每个样本 `wavelength_count` 与 `wl_<nm>` 特征列数是否一致；统计 `wl_` 列是否存在重复映射风险。若存在，建议改为保留小数（如 `wl_403.2`）或引入 band index（如 `band_012_wl_403.2`）。
3. **像素清洗强度检查**：从 `huajiao_metadata.parquet` 读取 `removed_ratio/coverage_ratio/valid_pixel_count`，与 val 误差做相关性/散点图。若发现清洗过猛（removed_ratio 高且误差增大），考虑二选一：只保留 `trimmed_mean`（不再先做 `clean_mask_extremes`）或放宽 `clip_low/high`。

**B. 预处理 + 基线复测（最可能带来提升）**

1. **加入 SG 平滑 + 一阶导**：在训练前对每条光谱做 SG 一阶导（窗口/多项式阶数用 CV 搜索），再做 PLSR（全波段与 GA 选波段都跑），对照验证是否能将 R² 拉升到更接近阶段二“SG 一阶导显著优于 Raw”的水平。
2. **系统搜索 `n_components`**：对固定波段集合，在训练集上用 CV 网格搜索 `n_components`（例如 1..min(15, n_features)），替代启发式固定，重点观察“极端样本回归均值”是否缓解。

**C. 若仍受限（再考虑）**

1. **分组评估**：按 `sample_dir.parent`（品类/批次）做 GroupKFold，确认模型到底在学“品类差异”还是“油含量差异”；若组内效果显著更差，需考虑域适配/分组归一化或补充样本。
2. **引入非线性回归对照**：SVR(RBF)/ExtraTrees 等作为对照基线；并尝试拼接 `coverage_ratio/valid_pixel_count`、`wl_*_std` 等统计量作为辅助特征，观察是否能提升对极端样本的拟合能力。
