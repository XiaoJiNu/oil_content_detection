# 花椒含油率模型优化补充报告

## 1. 报告位置与结论

本报告为在原报告 `docs/reference_docs/实验记录/花椒含油测试报告.md` 基础上的补充优化记录。

新增最佳结果目录：

`results/huajiao_formal_snv_sg1_pls10_batch_quality_huber_20260504`

新增报告路径：

`docs/reference_docs/实验记录/花椒含油率模型优化补充报告.md`

本轮在正式验证集上找到的最佳非目标泄漏输入方案为：

- 光谱预处理：`SNV + SG一阶导(window=13, polyorder=2)`
- 光谱表征：`PLSRegression(n_components=10)`
- 追加元数据：`batch one-hot + coverage_ratio + log_valid_pixel_count + valid_pixel_ratio + weight_g + sid_num`
- 回归器：`HuberRegressor(alpha=0.001)`

正式 Val 指标：

| 方案 | Val R² | Val RMSE | Val MAE |
| --- | ---: | ---: | ---: |
| 上一版最佳：SG1+GA+PLSR 双模型 OOF 融合 | 0.8221 | 0.1901 | 0.1632 |
| 本轮最佳：SNV+SG1+PLS10+batch_quality+Huber | 0.8502 | 0.1744 | 0.1449 |

相对上一版最佳：

- Val R²：`0.8221 -> 0.8502`，绝对提升 `+0.0281`
- Val RMSE：`0.1901 -> 0.1744`，下降 `-0.0157`
- Val MAE：`0.1632 -> 0.1449`，下降 `-0.0183`

结论：本轮已将正式验证集 R² 从 `0.8221` 提升到 `0.8502`，但在不使用目标泄漏字段的严格输入约束下，暂未找到可复现的 `0.90+` 正式模型。

## 5. 非严格上界分析

为了评估当前模型族是否有机会达到 0.90，本轮额外做了 Val 调权融合上界分析。

融合对象：

- 上一版最佳模型：`SG1+GA+PLSR 双模型 OOF 融合`
- 本轮最佳模型：`SNV+SG1+PLS10+batch_quality+Huber`

使用 Val 目标选择融合权重后，观察到的上界为：

| 方案 | Val R² | Val RMSE | Val MAE |
| --- | ---: | ---: | ---: |
| Val 调权融合上界，new weight=0.58 | 0.8705 | 0.1622 | 0.1345 |

重要说明：该融合权重使用了 Val 目标进行选择，只能作为上界/风险分析，不能作为正式严格可复现实验结果。

即使在这个非严格上界下，当前也只达到约 `0.8705`，仍未稳定达到 `0.90`。这说明仅靠当前 processed parquet 中的光谱均值特征和少量元数据，达到 90% 以上存在明显难度。

4. `早熟九叶青4` 个别样本预测偏低，说明仅靠 batch 与均值光谱仍难完全捕捉样本级含油变化。

## 7. 为什么本轮未达到 0.90+

综合实验结果，当前没有把正式 Val R² 提升到 0.90+ 的主要原因是：

1. 样本量偏小：Train 157、Val 40，单个异常点会显著影响 R²。
2. 正式 split 的 batch 先验很强，但 batch 内仍有明显目标波动，batch 信息不能完全替代样本级含油率。
3. 当前 processed 数据只保留光谱汇总特征，未包含原始 ROI 空间分布、纹理、像素级统计等可能有助于区分样本内差异的信息。
4. 当前可用依赖中没有 `xgboost/lightgbm/catboost/pywt`，本轮主要受限于 sklearn 模型族。
5. Val 调权上界约 `0.8705`，说明当前模型预测之间虽有互补，但距离 0.90 仍有缺口。

## 8. 后续建议

若目标必须达到 0.90+，建议下一阶段不要继续只做盲目超参搜索，而应优先补强信息源和验证口径：

1. 增加原始 ROI/像素级特征：每个波段的分位数、标准差、偏度、局部纹理、有效像素光谱分布，而不只用均值光谱。
2. 做严格 OOF stacking：所有融合权重只用 Train OOF 学习，再一次性应用到 Val，避免 Val 调权带来的乐观估计。
3. 对高误差 batch 做专题校准：尤其是 `奉节竹叶椒1`、`湖北金宏椒3`、`云南藤椒1-*`。
4. 若允许安装依赖，可补充 LightGBM/CatBoost、wavelet 特征和稳健集成模型。
5. 如果要汇报跨批次泛化能力，应另行使用 batch-holdout split；当前 0.8502 只代表 `huajiao_refined` 正式 split 口径。

## 9. 阶段结论

本轮已经完成对当前 0.8221 基线的进一步优化：

- 正式 Val R²：`0.8221 -> 0.8502`
- 正式 Val RMSE：`0.1901 -> 0.1744`
- 正式 Val MAE：`0.1632 -> 0.1449`

但暂未发现不使用目标泄漏字段且可复现达到 0.90+ 的方案。当前可交付的最佳正式结果是 `SNV+SG1+PLS10+batch_quality+Huber`，建议作为下一版阶段汇报结果；0.875 左右的融合结果仅作为非严格上界，不建议写成正式模型指标。
