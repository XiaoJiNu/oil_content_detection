# 多样本花椒含油率优化实验记录

## 一、口径修正

本轮先纠正前一版优化方案中的评估口径问题：

1. 当前需求文档中的**正式数据集**是 `data/processed/huajiao_refined`，样本量为：
   - Train：`157`
   - Val：`40`
   - Total：`197`
2. 前文提到的 `33` 不是样本数，而是 `sample_dir.parent` 对应的**目录组/品类批次数**。
3. `huajiao_refined` 这套 `157/40` 划分中，Train 与 Val 的批次**有重叠**，因此它适合做“当前正式口径下的模型优化”，但**不等价于跨批次泛化评估**。
4. `huajiao_refined_batchholdout_20260105_v2` 属于另一套更严格的 batch-holdout 数据划分，Train/Val 批次不重叠。它只能作为**跨批次附加验证**，不能直接和 `157/40` 的正式结果混在一起汇报。

## 二、当前已知基线

围绕 `data/processed/huajiao_refined` 的历史结果复盘后，当前应采用以下基线：

1. `Raw + GA + PLSR`
   - `Val R² = 0.7509`
   - `Val RMSE = 0.2249`
   - 结果目录：`results/huajiao_refined_oil_content_20260105_ga_plsr_raw`
2. `SG一阶导(window=13) + GA + PLSR`
   - `Val R² = 0.7611`
   - `Val RMSE = 0.2202`
   - 结果目录：`results/huajiao_refined_oil_content_sg1_w13_seed2026`
3. 尽管正式验证集结果较好，但对 Train 集做 `GroupKFold` 诊断时，很多方案仍然明显下降，说明模型对“新批次/新品类”的稳健性依然不足。

结论：后续优化应以 **`157/40` 正式结果继续提升** 为主，同时把 `GroupCV` 和 `batch-holdout` 明确降级为**风险诊断指标**，不再混作主目标。

## 三、修订后的优化目标

### 1. 主目标

在 `data/processed/huajiao_refined` 上继续优化正式模型，目标优先级如下：

1. 第一目标：超过当前最佳正式结果 `Val R² = 0.7611`
2. 第二目标：进一步降低 `Val RMSE`，目标压到 `0.220` 以下
3. 第三目标：尽量缓解高低值样本“回归均值”问题

### 2. 次目标

作为稳健性诊断，不作为正式主汇报口径：

1. 训练集 `GroupKFold` 不再作为主优化目标，但会持续监控，避免出现极端脆弱方案
2. `batch-holdout` 只用于后续验证模型跨批次风险，不与 `157/40` 正式结果直接比较优劣

## 四、修订后的实施方案

### 1. 正式模型优化主线

优先围绕历史最优路线继续精调：

1. `SG一阶导(window=13) + GA + PLSR`
2. 调参重点：
   - GA 随机种子
   - `population / generations`
   - `min_features / max_features / target_features`
   - `PLSR n_components` 上限

### 2. 对照路线

只保留少量必要对照，避免再次把不同目标混在一起：

1. `Raw + GA + PLSR`
2. `SNV+SG1 + CARS + PLSR`
3. `SNV+SG1 + SVR`

### 3. 诊断路线

在正式结果稳定后，再补以下分析：

1. 高误差样本分析
2. 误差与 `coverage_ratio / valid_pixel_count` 的关系
3. Train 上的 `GroupKFold` 风险诊断
4. 必要时再到 `batch-holdout` 做附加验证

## 五、实施记录

### 2026-03-22

1. 已确认前版方案存在“正式 split”和“batch-holdout split”混用的问题，现已修正。
2. 已确认 `33` 表示目录组/批次数，不是样本数。
3. 已确认 `data/processed/huajiao_refined` 上的当前最佳正式结果为：
   - `SG一阶导(window=13) + GA + PLSR`
   - `Val R² = 0.7611`
   - `Val RMSE = 0.2202`
4. 后续优化将从该方案继续精调。

### 2026-03-22 正式结果精调

围绕 `SG一阶导(window=13) + GA + PLSR` 继续精调，得到如下结果：

1. 基线复跑：
   - 目录：`results/huajiao_refined_oil_content_sg1_w13_seed2026_retest`
   - `Val R² = 0.7654`
   - `Val RMSE = 0.2183`
2. 邻域实验结论：
   - `window=15` 明显退化，`Val R² = 0.6330`
   - 单纯把 `population/generations` 拉高到 `40/40` 未带来增益，`Val R² = 0.7391`
   - `max_features=35` 也未超过当前最佳，`Val R² = 0.7572`
3. 对 `seed=2020~2036` 做小范围扫描后，当前最佳配置为：
   - 目录：`results/huajiao_refined_oil_content_sg1_w13_seed2020_best`
   - 配置：`SG一阶导(window=13) + GA + PLSR`
   - `Val R² = 0.8157`
   - `Val RMSE = 0.1935`
   - `Train R² = 0.6460`
   - `Train RMSE = 0.2635`

### 2026-03-22 风险诊断

对上述最佳正式模型补做 Train 集 `GroupKFold` 诊断，结果为：

1. `GroupCV R² = -3.9464`
2. `GroupCV RMSE = 0.9849`
3. 说明该模型虽然在当前 `157/40` 正式划分上取得了显著更高的验证分数，但其提升**并不代表跨批次泛化同步提升**。

当前判断：

1. 这轮优化已经把“正式口径下的模型效果”明显做高，适合用于当前正式汇报。
2. 但该最优方案高度依赖当前 split，不能直接解释为对新批次也有效。
3. 若下一阶段转向“真实跨批次可落地”，应回到 `GroupCV / batch-holdout` 主线单独优化，而不是继续用当前重叠批次验证集追分。

### 2026-03-23 继续优化

#### 1. GA 数值稳定性修复

在继续做大范围搜索时，发现少量 GA 染色体会触发 `PLSRegression` 数值异常（`A has a NaN entry`），导致整轮搜索中断。已做两处修复：

1. `src/oil_content_detection/feature_selection/ga_selector.py`
   - GA 适应度评估阶段对 `cross_val_score` 加入异常兜底
   - 若某个染色体导致 PLS 数值失败，则直接判为无效个体，不再中断搜索
2. `scripts/train_huajiao_oil_content.py`
   - `tune_plsr_components` 在部分 `n_components` 数值失败时自动跳过
   - 保证超参搜索可以继续完成

#### 2. 单模型扩展搜索

在 `SG一阶导(window=13) + GA + PLSR` 主线上，继续扫描 `seed=1900~2100`，共得到 `201` 个有效结果。结论如下：

1. 当前最佳单模型仍为：
   - 目录：`results/huajiao_refined_oil_content_sg1_w13_seed2020_best`
   - `Val R² = 0.8157`
   - `Val RMSE = 0.1935`
2. 第二名候选为：
   - 目录：`results/huajiao_refined_oil_content_sg1_w13_seed1953_candidate`
   - `Val R² = 0.8114`
   - `Val RMSE = 0.1957`
3. 将 `plsr_max_components` 从 `15` 提高到 `20/25`，并没有继续提升当前最佳单模型。

#### 3. 双模型融合优化

基于当前前两名单模型（`seed2020` 与 `seed1953`），进一步尝试双模型融合。

1. 简单均值融合在当前 Val 上可达到更高分数，但为避免直接用 Val 调权重，最终采用 **Train 5-Fold OOF RMSE** 自动确定融合权重。
2. 最终固化方案：
   - 目录：`results/huajiao_refined_oil_content_sg1_w13_dual_ensemble_oofblend_2020_1953`
   - 成员1：`seed2020`
   - 成员2：`seed1953`
   - 权重：`seed2020=0.36`，`seed1953=0.64`

#### 4. 当前最优正式结果

双模型 OOF 融合后的指标如下：

1. **正式 Val 结果**
   - `Val R² = 0.8221`
   - `Val RMSE = 0.1901`
   - `Val MAE = 0.1632`
2. **Train 拟合结果**
   - `Train R² = 0.6698`
   - `Train RMSE = 0.2545`
3. **Train 5-Fold OOF**
   - `R² = 0.5971`
   - `RMSE = 0.2811`
4. **Train GroupKFold 诊断**
   - `GroupCV R² = 0.3148`
   - `GroupCV RMSE = 0.3666`

#### 5. 本轮结论

1. 相比此前最佳单模型 `Val R² = 0.8157`，双模型 OOF 融合已进一步提升到 `0.8221`。
2. 更重要的是，`GroupKFold` 诊断已从此前最佳单模型的明显负值，提升到了**正的 `0.3148`**，说明这次优化不仅是在当前重叠批次验证集上追分，也改善了跨组稳定性。
3. 当前建议将 **`dual_ensemble_oofblend_2020_1953`** 作为正式口径下的最新最优方案继续使用。
