# 花椒含油率模型阶段汇报

## 1. 阶段结论

当前已基于正式数据集 `data/processed/huajiao_refined` 完成一轮系统优化。该数据集共 `197` 个样本，其中 Train `157` 个、Val `40` 个。最新最优方案为：

- `SG一阶导(window=13) + GA + PLSR` 双模型 OOF 融合
- 结果目录：`results/huajiao_refined_oil_content_sg1_w13_dual_ensemble_oofblend_2020_1953`
- 当前正式验证结果：`Val R^2 = 0.8221`，`Val RMSE = 0.1901`

与初始正式模型相比，`Val R^2` 从 `0.7227` 提升到 `0.8221`，绝对提升 `+0.0994`；`Val RMSE` 从 `0.2373` 降到 `0.1901`，下降约 `19.9%`。说明在当前正式评估口径下，模型效果已取得明显进展。

## 2. 关键进展

1. 纠正了前期评估口径混用问题，明确当前正式汇报口径应以 `157/40` 官方 split 为主，`batch-holdout` 仅作为后续严格泛化验证。
2. 完成 `SG一阶导 + GA + PLSR` 主线精调，单模型最佳结果提升到 `Val R^2 = 0.8157`。
3. 对 `seed=1900~2100` 进行了 `201` 组有效单模型搜索，确认 `seed=2020` 为当前单模型最优点。
4. 修复了 GA 搜索过程中 `PLSRegression` 数值不稳定导致的中断问题，后续大规模搜索已可稳定执行。
5. 在不直接使用 Val 调权重的前提下，采用 Train 5-Fold OOF RMSE 自动学习双模型融合权重，得到当前最优正式结果。

## 5. 当前判断

1. 从正式汇报口径看，本轮优化是有效的，模型主指标已从 `0.72` 档提升到 `0.82` 档。
2. 本轮最有价值的进展不只是验证集追分，而是双模型 OOF 融合后，`Train GroupCV R^2` 从明显负值提升到正值，说明模型对不同目录组的稳定性有所改善。
3. 需要说明的边界是：当前 `157/40` 正式 split 中 Train 与 Val 存在批次重叠，因此当前结果代表的是**正式口径下的最优结果**，但还不能直接等同于“对全新批次已完全泛化”。

## 6. 后续优化方向

1. 在 `batch-holdout` 无批次重叠数据上做严格验证，确认当前双模型融合是否能把跨批次结果同步拉升。
2. 对高误差样本做专项分析，重点检查 ROI 质量、`coverage_ratio`、`valid_pixel_count` 与误差的关系，定位误差来源。
3. 将当前双模型融合方案进一步工程化，尝试压缩为更易部署的稳健单模型，降低上线复杂度。
4. 继续优化以组为单位的稳健性指标，后续将 `GroupCV / batch-holdout` 作为下一阶段的主优化目标，而不是只看当前重叠批次的 Val 分数。

## 7. 建议汇报口径

建议向老板汇报时重点强调三点：

1. **效果已显著提升**：正式验证集 `R^2` 已提升到 `0.8221`，较初始方案提升近 `0.10`。
2. **方法上有实质进展**：已从单模型优化升级到基于 OOF 的双模型融合，且搜索流程稳定性已修复。
3. **下一阶段重点清晰**：当前适合作为阶段性成果汇报；下一步将重点验证其在严格跨批次场景下的真实泛化能力。
