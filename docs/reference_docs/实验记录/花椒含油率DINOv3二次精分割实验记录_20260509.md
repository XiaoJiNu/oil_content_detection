## 1. 目标

本轮目标是在已完成的 DINOv3 coarse polygon ROI 基础上，确认下游含油率指标偏低的原因，并把更适合含油率光谱聚合的 ROI 口径接入 serving/package 全链路。

约束保持不变：

- 应用侧输入只能是同视角、同尺寸的 RGB 图像 + ENVI 高光谱 cube。
- serving feature 只能来自上传文件可直接计算的 `wl_*` ROI 平均光谱和 ROI 质量特征。
- 不允许使用 `weight_g`、`batch`、`sid_num`、`distill_ml`、`oil_ml_per_gram` 或目标标签字段作为 serving feature。
- DINOv3 ROI artifact 与含油率回归 artifact 分开版本化；含油率 artifact 的 `roi_config.json` 固定 DINOv3 后端和 refinement 配置。

## 2. 根因确认

上一轮 DINOv3 ROI 分割模型学习的是 CVAT 手工 coarse polygon。该 polygon 用于“定位样本区域”表现很好，但对于含油率 cube 光谱聚合来说 coverage 过大，会混入纸张、背景、红底或非花椒区域光谱。

本轮 refined 评估再次验证了这个根因。

| 口径 | Train mean coverage | Val mean coverage | 说明 |
| --- | ---: | ---: | --- |
| DINOv3 coarse polygon | 0.438004 | 0.447387 | 明显偏大，接近整张图的一半 |
| hand refined mask / refined reference | 0.174362 | 0.178381 | 与历史手工 refined ROI / 传统自动 ROI 的 0.16-0.18 区间一致 |
| DINOv3 + gray_otsu refined | 0.167443 | 0.170751 | 回到合理 ROI 覆盖率区间 |
| DINOv3 + color_texture in mask | 0.323133 | 0.330944 | 仍偏大，保留过多非花椒像素 |

结论：DINOv3 coarse polygon 下游效果差，主要不是 PLS/Huber/Ridge 回归器本身的问题，而是 ROI 光谱口径污染问题。

## 4. ROI refinement 方法

### 4.1 gray_otsu refined

流程：

1. DINOv3 ROI predictor 先输出 coarse polygon mask。
2. 在 polygon mask 内调用传统 `segment_pepper_in_mask`。
3. 使用 `segmentation_mode=gray_otsu` 只保留更像花椒颗粒的区域。
4. 将最终 refined mask 用于 cube 光谱聚合、debug mask/overlay 和 `roi.mask_source`。

冻结配置：

```json
{
  "backend": "dinov3",
  "dinov3": {
    "artifact_dir": "../huajiao-dinov3-roi-seg-v0.1.0",
    "mask_source": "dinov3_roi_segmentation",
    "post_refinement": {
      "enabled": true,
      "segmentation_mode": "gray_otsu",
      "pepper_open_size": 5,
      "pepper_close_size": 5,
      "hole_fill_max_area": 300,
      "label_fallback_enabled": false,
      "label_max_area_ratio": 0.0
    }
  }
}
```

最终 serving mask source：`dinov3_roi_gray_otsu_refined`。

### 4.2 color_texture in mask

流程同样先用 DINOv3 coarse polygon 定位，再在 polygon 内做 color/texture 分割。该方法 validation top-line 也较好，但 coverage 仍约 0.33，mask precision 与 IoU 明显低于 gray_otsu，因此当前不作为首选 serving artifact。

## 5. Mask 质量对比

### 5.1 Train split

| 策略 | coverage_pred mean | Dice vs refined | IoU vs refined | Precision | Recall |
| --- | ---: | ---: | ---: | ---: | ---: |
| DINOv3 coarse polygon | 0.438004 | 0.565275 | 0.395522 | 0.395540 | 0.999891 |

| DINOv3 + color_texture in mask | 0.323133 | 0.697701 | 0.536453 | 0.536730 | 0.998943 |

### 5.2 Val split

| 策略 | coverage_pred mean | Dice vs refined | IoU vs refined | Precision | Recall |
| --- | ---: | ---: | ---: | ---: | ---: |
| DINOv3 coarse polygon | 0.447387 | 0.563629 | 0.394781 | 0.394807 | 0.999849 |

| DINOv3 + color_texture in mask | 0.330944 | 0.695109 | 0.533682 | 0.533995 | 0.998766 |

结论：

- gray_otsu refined 将 DINOv3 coarse polygon 从 0.44 coverage 拉回到 0.17 左右。
- gray_otsu refined 与 hand refined mask 的重合度最高，val Dice≈0.963、val IoU≈0.929。
- color_texture recall 接近 1，但 precision 和 IoU 较低，说明保留了太多非目标区域。

## 6. 下游含油率模型结果

模型族保持报告复现路线的 deployable 变体：

- SNV
- Savitzky-Golay 一阶导，`window_length=13`、`polyorder=2`、`deriv=1`
- PLS score 表示
- compact linear regressor：Ridge 或 Huber
- 拼接 ROI quality features：`coverage_ratio`、`log_valid_pixel_count`、`valid_pixel_ratio`
- 不使用重量、批次、样本编号或标签字段作为特征

### 6.1 固定 validation 最优

| Dataset | PLS n | Regressor | Alpha | Train R² | Train RMSE | Train MAE | Val R² | Val RMSE | Val MAE | OOF R² |
| --- | ---: | --- | ---: | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| dino_gray_otsu_refined | 12 | ridge | 0.01 | 0.639776 | 0.265788 | 0.205741 | 0.777996 | 0.212330 | 0.170691 | 0.408613 |
| dino_color_texture_in_mask | 13 | huber | 1.0 | 0.640014 | 0.265700 | 0.196621 | 0.768468 | 0.216839 | 0.180497 | 0.439344 |

### 6.2 OOF 最优

| Dataset | PLS n | Regressor | Alpha | OOF R² | OOF RMSE | OOF MAE | Val R² | Val RMSE | Val MAE |
| --- | ---: | --- | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| dino_gray_otsu_refined | 20 | ridge | 30.0 | 0.475396 | 0.320749 | 0.244203 | 0.596926 | 0.286104 | 0.245308 |
| dino_color_texture_in_mask | 16 | ridge | 30.0 | 0.498687 | 0.313548 | 0.237806 | 0.661050 | 0.262361 | 0.204593 |

解释：

- 若只看固定 validation top-line，gray_otsu refined 最优，Val R²≈0.778。
- 若按 train-side OOF 选择，color_texture 的 OOF R²更高，但 validation R²只有≈0.661，gray_otsu 的 OOF 最优组合 validation R²也下降到≈0.597。
- 因此本轮推荐 gray_otsu refined 作为 serving 候选，但必须明确：小样本下存在 validation 选择敏感性，不能把单一 validation-top 结果当作独立泛化保证。

## 12. 推荐结论

当前推荐把以下 artifact 作为新的最佳 DINOv3 serving 候选：

```text
/home/yr/yr/code/cv/oil_content_detection/artifacts/huajiao-oil-content-dinov3-gray-otsu-refined-roi-v0.3.1
```

推荐理由：

1. 满足部署输入约束：RGB image + same-size ENVI cube。
2. 不依赖 `weight_g`、`batch`、`sid_num`、标签目标等应用端不可用字段。
3. ROI coverage 从 DINOv3 coarse polygon 的 train≈0.438、val≈0.447 降回 train≈0.167、val≈0.171。
4. 与 hand refined ROI mask 高度一致：val Dice≈0.963、val IoU≈0.929。
5. 固定 validation 指标达到 Val R²≈0.778、RMSE≈0.212、MAE≈0.171。
6. 明显优于当前文档中的原 DINOv3 coarse v0.3.0 打包指标 Val R²=0.603312，并优于传统自动 ROI v0.2.1 记录的 Val R²≈0.707-0.715。
7. 接近/超过当前手工 refined 小网格固定 validation 记录 Val R²≈0.752，但不使用应用端不可用字段。

## 13. 风险与后续建议

仍需保留的风险：

1. 小样本验证集调参敏感：gray_otsu 的 validation-top 组合 OOF R²≈0.409；按 OOF 选择时 validation R²降到≈0.597。
2. color_texture 的 best-OOF 更高，但 mask coverage 和 overlap 质量较差，不宜仅凭 OOF 作为 serving 首选。
3. 当前 validation split 不是严格跨产地/跨批次/跨设备独立泛化评估。
4. 上游拍摄背景、红底、标签、光照变化可能影响 DINOv3 coarse polygon 和 in-polygon refinement 的最终 mask。

建议后续：

- 以 OOF/CV 或嵌套选择为主重新选超参，降低 validation-top 选择偏差。
- 对 gray_otsu morphology 参数做小网格：`open_size`、`close_size`、`hole_fill_max_area`。
- 补充独立外部样本或新采集样本，优先验证 overlay、coverage、prediction residual。
- 增加 artifact 加载层测试，明确拒绝 feature_schema 中出现泄漏字段。
- 增加 `roi_config` path 安全检查，确保相对 DINOv3 artifact path 落在预期 artifacts 布局内。
