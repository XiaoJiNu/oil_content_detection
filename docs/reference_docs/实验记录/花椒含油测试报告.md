# 花椒含油率模型阶段汇报

## 1. 阶段结论

当前数据集共 `197` 个样本，其中 Train `157` 个、Val `40` 个。最新最优方案为：

- `SG一阶导(window=13) + GA + PLSR` 双模型融合
- 当前正式验证结果：`Val R^2 = 0.8221`，`Val RMSE = 0.1901`

与初始正式模型相比，`Val R^2` 从 `0.7227` 提升到 `0.8221`，绝对提升 `+0.0994`；`Val RMSE` 从 `0.2373` 降到 `0.1901`，下降约 `19.9%`。模型效果已取得明显进展，但未达到90%以上。

## 2. 关键进展

1. 完成 `SG一阶导 + GA + PLSR` 主线精调，单模型最佳结果提升到 `Val R^2 = 0.8157`。
2. 对 `seed=1900~2100` 进行了 `201` 组有效单模型搜索，确认 `seed=2020` 为当前单模型最优点。
3. 修复了 GA 搜索过程中 `PLSRegression` 数值不稳定导致的中断问题，后续大规模搜索已可稳定执行。
4. 采用自动学习双模型融合权重，得到当前最优正式结果。

## 3. 指标对比

| 阶段         | 方案                            | Val R^2 | Val RMSE | Train GroupCV R^2 | 说明                               |
| ------------ | ------------------------------- | ------: | -------: | ----------------: | ---------------------------------- |
