# 花椒含油率模型实验进展报告-20260505

## 1. 阶段结论

当前数据集共 `197` 个样本，其中 Train `157` 个、Val `40` 个，光谱波段 `224` 个。上一阶段最优方案为：

- `SG一阶导(window=13) + GA + PLSR` 双模型融合
- 上一阶段正式验证结果：`Val R^2 = 0.8221`，`Val RMSE = 0.1901`，`Val MAE = 0.1632`

本轮在排除 `distill_ml`、`oil_ml_per_gram`、`oil_ml_per_100g` 等目标相关字段后，当前最优方案更新为：

- `SNV + SG一阶导(window=13, polyorder=2) + PLSR(10) + batch/quality特征 + Huber回归`
- 本轮正式验证结果：`Val R^2 = 0.8502`，`Val RMSE = 0.1744`，`Val MAE = 0.1449`

**与上一阶段最优方案相比，`Val R^2` 从 `0.8221` 提升到 `0.8502`，绝对提升 `+0.0281`，相对提升约 `3.4%`；`Val RMSE` 从 `0.1901` 降到 `0.1744`，绝对下降 `0.0157`，下降约 `8.2%`；`Val MAE` 从 `0.1632` 降到 `0.1449`，绝对下降 `0.0183`，下降约 `11.2%`。**

若与初始正式模型相比，`Val R^2` 已从 `0.7227` 提升到 `0.8502`，绝对提升 `+0.1275`，相对提升约 `17.6%`；`Val RMSE` 从 `0.2373` 降到 `0.1744`，下降约 `26.5%`。

## 2. 关键进展

1. 完成 `SNV + SG一阶导 + PLS低维表征 + 稳健回归` 路线补充实验，本轮最佳模型达到 `Val R^2 = 0.8502`。
2. 模型输入继续排除含油率目标值及其直接派生字段，避免把实验室测量结果带入训练。
3. 本轮最佳方案引入批次类别与图像质量类特征，包括 `batch one-hot`、`coverage_ratio`、`log_valid_pixel_count`、`valid_pixel_ratio`、`weight_g`、`sid_num`。
4. `HuberRegressor` 对少量异常样本更稳健，与 `PLSRegression(n_components=10)` 组合后，验证集 RMSE 和 MAE 均有下降。
5. 残差复查显示，当前主要误差仍集中在少数低值被高估、高值被低估的样本上，后续需要进一步补充样本内部信息。

### 4.3 类别均衡性判断

1. 按大类合并后，Train 和 Val 都覆盖了全部 `11` 个大类，不存在某个大类只在训练集或只在验证集中出现的问题，验证集覆盖面比按小编号统计时更合理。
2. 类别数量仍不均衡。Train 中最多的是 `云南藤椒`，有 `27` 个样本；最少的是 `韩城大红袍`，只有 `4` 个样本，最大/最小比例约 `6.8:1`。
3. Val 中最多的是 `云南藤椒`，有 `8` 个样本；`云南竹叶椒`、`刺壳`、`枸椒`、`韩城大红袍` 各只有 `2` 个样本，最大/最小比例为 `4:1`。因此当前 Val 可以用于观察总体指标变化，但对少数大类的单类结论仍不够稳定。
4. 从含油率均值看，各大类差异明显，例如 `云南竹叶椒` 均值约 `2.3573`，`韩城大红袍` 均值约 `0.4588`。模型可能会利用大类先验获得较好结果，因此后续需要同时关注大类内样本差异，而不能只看总体 R^2。
5. 当前本轮模型使用了 `batch_quality` 特征，批次/类别信息对正式 split 有帮助，但如果后续要证明跨产地、跨批次泛化能力，还需要单独设计更严格的 batch-holdout 或 category-holdout 验证。

## 6. 误差观察

本轮最佳模型在 Val 中误差较大的样本如下：

| sample_id | batch | actual | predicted | error | abs_error |
| --- | --- | ---: | ---: | ---: | ---: |
| 0193_11 | 奉节竹叶椒1 | 0.9292 | 1.2893 | 0.3601 | 0.3601 |
| 0351_11 | 湖北金宏椒3 | 2.3013 | 1.9678 | -0.3334 | 0.3334 |
| 0196_11 | 奉节竹叶椒1 | 0.8787 | 1.1961 | 0.3174 | 0.3174 |
| 0164_11 | 云南藤椒1-1 | 0.9422 | 1.2526 | 0.3104 | 0.3104 |
| 0169_11 | 云南竹叶椒2 | 2.1064 | 2.4144 | 0.3080 | 0.3080 |

主要现象：

1. `奉节竹叶椒1` 两个低值样本被预测偏高，是当前 MAE/RMSE 的主要来源之一。
2. `湖北金宏椒3` 高值样本仍有低估现象。
3. `云南藤椒1-*` 内部存在样本级差异，单靠批次类别和均值光谱还不能完全区分。
4. 继续提升模型效果时，应重点补充 ROI 内部像素分布、分位数、波段方差和纹理等信息。

## 7. 下一阶段建议

结合按大类合并后的数据分布，下一阶段不建议只继续做模型超参搜索，应优先补强数据覆盖、类别均衡和样本内部表达。

1. **需要继续增加数据**：当前总样本量为 `197` 个，按大类看只有 `11` 类，单类样本量仍偏小。尤其是 `韩城大红袍` 总样本只有 `6` 个，`刺壳` 和 `大巴山野生椒` 各 `11` 个，明显少于 `云南藤椒`、`早熟九叶青`、`枸椒` 等类别。
2. **优先补充少样本大类**：建议优先补充 `韩城大红袍`、`刺壳`、`大巴山野生椒`、`贵州藤椒`、`云南竹叶椒`。如果条件允许，可先把每个大类的训练样本补到不少于 `15` 个，验证样本补到不少于 `5` 个。
3. **补齐验证集薄弱大类**：当前 Val 中 `云南竹叶椒`、`刺壳`、`枸椒`、`韩城大红袍` 都只有 `2` 个验证样本；`大巴山野生椒`、`奉节竹叶椒` 也只有 `3` 个验证样本。后续新增验证样本时应优先覆盖这些大类，避免少数样本决定单类误差判断。
4. **继续补充高误差相关类别样本**：本轮残差较大的样本主要涉及 `奉节竹叶椒`、`湖北金宏椒`、`云南藤椒`、`云南竹叶椒` 等大类。建议在这些大类内部补充不同含油率区间的样本，尤其是低含油率和高含油率端点样本。

## 8. 总结

1. **效果继续提升**：本轮正式验证集 $R^2$ 达到 `0.8502`，较上一阶段最优提升 `+0.0281`，相对提升约 `3.4%`。
2. **误差明显下降**：`Val RMSE` 较上一阶段下降约 `8.2%`，`Val MAE` 下降约 `11.2%`。
3. **当前正式推荐方案**：`SNV + SG一阶导 + PLS10 + batch_quality + Huber`。
4. **后续重点**：下一阶段应优先补充少样本大类和高误差大类样本，同时增加 ROI/像素级统计特征，并新增更严格的跨批次验证口径。
