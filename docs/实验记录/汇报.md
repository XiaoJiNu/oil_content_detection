# 花椒含油率高光谱建模实验汇报

## 1. 实验概况

本报告基于 [20251222需求整理.md](../../docs/reference_docs/功能需求文档/20251118需求整理/20251222需求整理.md) 中最新一轮已落地实验结果整理，使用的是“人工标注大轮廓 + 轮廓内灰度 Otsu 精细分割”生成的 ROI 数据。当前用于建模的数据集共 **197 个样本**，其中 **157 个训练样本**、**40 个验证样本**。每个样本包含 **224 个波长特征**，波段范围为 **398 nm 到 1004 nm**，预测目标为 **`oil_ml_per_100g`（含油率）**。训练集标签范围为 **0.3094 到 3.1701 ml/100g**，验证集范围为 **0.3651 到 2.4500 ml/100g**。

## 2. 本轮方案与结果

本轮实验采用文档中已记录的正式训练方案：

| 项目     | 配置                                     |
| -------- | ---------------------------------------- |
| 数据来源 | `data/processed/huajiao_refined`       |
| 训练脚本 | `scripts/train_huajiao_oil_content.py` |
| 目标变量 | `oil_ml_per_100g`                      |
| 特征选择 | GA（20 代，种群 20，随机种子 2024）      |
| 回归模型 | PLSR                                     |
| 输入特征 | GA 选中的 ROI 聚合光谱                   |

模型结果如下：

| 数据集 | 样本数 |    R² | RMSE (ml/100g) |
| ------ | -----: | -----: | -------------: |
| Train  |    157 | 0.6079 |         0.2773 |
| Val    |     40 | 0.7227 |         0.2373 |

本轮模型共选出 **26 个关键波长**，分别为：

`448, 503, 532, 564, 572, 602, 615, 623, 631, 642, 658, 672, 680, 724, 726, 740, 743, 751, 770, 800, 803, 806, 811, 922, 928, 978 nm`

从结果看，基于精细化 ROI 的 GA-PLSR 路线已经具备较稳定的含油率预测能力，验证集 `R²=0.7227`，说明模型可以解释约七成以上的含油率变化。

## 3. 验证集误差分析

验证集共 **40 个样本**，平均绝对误差（MAE）为 **0.2025 ml/100g**，中位绝对误差为 **0.1873 ml/100g**，最大绝对误差为 **0.4781 ml/100g**。从预测分布看，验证集真实值标准差为 **0.4564**，预测值标准差为 **0.3826**，说明当前模型存在一定“回归均值”现象，即对低值样本偏高估、对高值样本偏低估，这与需求文档中的分析结论一致。

误差最大的 5 个验证样本如下：

| 样本 ID | 实际值 | 预测值 | 绝对误差 |
| ------- | -----: | -----: | -------: |
| 0292_11 | 0.8886 | 1.3667 |   0.4781 |
| 0193_11 | 0.9292 | 1.3762 |   0.4470 |
| 0264_11 | 1.5272 | 1.0922 |   0.4350 |
| 0360_11 | 1.7503 | 1.3555 |   0.3948 |
| 0237_11 | 2.1654 | 1.7892 |   0.3762 |

整体上，模型对中间区间样本拟合较稳，但在极端高低值样本上仍有收缩现象。结合需求文档中的复盘，这更可能与多批次样本异质性、原始反射率未做更强预处理、以及部分样本 ROI 与背景混合带来的噪声有关。

## 5. 当前结论

基于人工标注大轮廓和灰度 Otsu 精细分割后的 ROI 数据，当前 GA-PLSR 模型已经完成了较完整的一轮正式训练与验证，验证集取得 **R²=0.7227、RMSE=0.2373 ml/100g** 的结果，说明该路线具备实际可用性。现阶段的主要问题不是模型失效，而是对极端样本仍存在欠拟合和方差收缩。下一步建议优先围绕文档中已提出的三项方向继续推进：一是核查 ROI 与高光谱立方体的空间对齐；二是补充 SG 一阶导、SNV/MSC 等光谱预处理对照；三是引入 SVR 等非线性模型作为基线，以进一步提升跨批次样本的泛化能力。
